# 🚀 Módulo 0: Fundamentos y Cultura DevOps

Bienvenido al inicio del camino **Zero to Hero**.
Antes de aprender a usar herramientas complejas (Docker, Kubernetes, Jenkins), es obligatorio entender **qué problemas resuelven**.

Este módulo establece la base teórica necesaria para entender **el "Porqué"** detrás del código. Sin esta base, DevOps es solo una lista de herramientas sin sentido.

## 🔗 ¿Cómo se conectan estos conceptos?

La lógica de este módulo introductorio sigue la creación de una empresa tecnológica moderna:

1.  **Definimos el método (Tema 1):** Decidimos que no podemos tardar 6 meses en lanzar software (Waterfall). Necesitamos ser rápidos (Agile).
2.  **Formamos el equipo (Tema 2):** Para ser rápidos, Desarrollo y Operaciones no pueden ser enemigos. Creamos una Cultura DevOps de colaboración.
3.  **Elegimos el terreno (Tema 3):** No vamos a comprar servidores y cables (On-premise). Alquilaremos potencia en la **Nube** (IaaS/PaaS) para escalar rápido.
4.  **Preparamos el cimiento (Tema 4):** Esa nube funciona con **Linux**. Necesitamos saber movernos por la terminal para controlarla.
5.  **Construimos la fábrica (Tema 5):** Para no cometer errores humanos, creamos una tubería automática (**CI/CD**) que lleva el código del desarrollador a la nube.

> 💡 **Objetivo:** Al terminar este módulo, no habrás escrito código complejo todavía, pero **entenderás perfectamente la arquitectura y el flujo de trabajo** de un Ingeniero DevOps Senior.
