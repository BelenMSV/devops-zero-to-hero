# 🐧 Módulo 3: Dominando Linux

> "Linux es la base sobre la que se sustenta DevOps y todo este curso. Aquí comienza tu verdadera fuerza técnica."

Si el Módulo 2 fue sobre crear la infraestructura, este módulo trata sobre **cómo controlarla**. Aprenderemos a movernos por la terminal, gestionar archivos, usuarios, permisos y procesos con máxima eficiencia.

## 🎯 Los 4 Pilares del Módulo
Nos centraremos en dominar estas áreas clave:
1.  **Comandos:** Copiar, mover, editar y manipular archivos.
2.  **Archivos:** Entender el sistema de archivos y permisos.
3.  **Software:** Gestión de paquetes (instalar/actualizar).
4.  **Servidores:** Configuración de servicios web y bases de datos.
